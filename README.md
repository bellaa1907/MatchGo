# MatchGo

**Trova persone con cui giocare.**

MatchGo è una piattaforma web che permette agli utenti di organizzare partite sportive, trovare altri giocatori e unirsi agli incontri disponibili.

L'obiettivo è semplificare l'organizzazione delle partite e aiutare le persone a trovare nuovi compagni di squadra.

## Funzionalità

- Gestione dei profili utente
- Creazione e ricerca di partite
- Partecipazione agli incontri
- Supporto per diversi sport: calcio, calcetto, basket, tennis e padel
- Gestione dei luoghi di gioco
- Valutazioni dei giocatori

## Tecnologie

- C#
- ASP.NET Core
- HTML e CSS
- JavaScript
- Entity Framework Core
- SQL

## Stato del progetto

**In sviluppo**

MatchGo è un progetto in evoluzione, con nuove funzionalità e miglioramenti previsti durante lo sviluppo.
